# Technical-Docs-Portfolio
Este repositorio contiene una recopilación de resúmenes basados en las documentaciones técnicas originales de mis proyectos.

El objetivo es proporcionar una visión sobre las arquitecturas implementadas, metodologías de trabajo, resolución de problemas técnicos y tecnologias implemantadas, omitiendo datos sensibles para respetar la privacidad de las empresas con las que he trabajado. Mostrando unicamente los esquemas de trabajo y las soluciones técnicas.
